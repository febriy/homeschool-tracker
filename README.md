# Wonder and Worship · My Learning Loop

A single-page homeschool loop tracker for the Yeo family.

## Run locally

Open `index.html` in a browser.

## Deploy to Vercel

Connect this repository to Vercel. The app is a static HTML page at the repository root; no build command is required.

## Progress storage

The tracker stores progress and notes in browser `localStorage`. Each browser and site origin keeps its own copy. Deploying to a new Vercel URL starts with separate browser storage.
